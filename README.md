# ManakAI

## BIS Intelligence Assistant

ManakAI is an AI-powered, evidence-backed assistant for discovering, understanding, and navigating Bureau of Indian Standards (BIS) information.

Developed as part of **Smart India Hackathon (SIH)**.

---

## 🎯 Project Objective

The assistant searches only official BIS documents and government-approved resources to provide accurate, source-backed information.

The system:

- Searches only indexed BIS data
- Returns evidence with every answer
- Displays official references
- Does not search the internet during queries
- Does not generate answers using an LLM
