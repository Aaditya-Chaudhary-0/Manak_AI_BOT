# Backend

This directory contains the FastAPI backend for ManakAI.

## Responsibilities

- FastAPI REST APIs
- Document Ingestion
- PDF Parsing
- Website Scraping
- Chunking
- Embedding Generation
- Qdrant Integration
- Semantic Search
- PostgreSQL Integration
- Fetch.ai Agentverse
